# LiftOS

אפליקציית Android אישית לתיעוד אימוני כוח, ניהול תוכניות, מדדי גוף והתקדמות. עובדת לגמרי ללא אינטרנט, בעברית ו-RTL,
עם עיצוב כהה בגוון פחם והדגשות ירוק-ליים. כל הנתונים נשמרים על המכשיר בלבד.

* Kotlin, Jetpack Compose, Material 3, Room (SQLite), Coroutines/StateFlow, Navigation Compose, DataStore
* שני מודולים: `:domain` (לוגיקה טהורה, נבדקת על ה-JVM) ו-`:app` (Android)
* פרטים: [FEATURES.md](FEATURES.md) · [ARCHITECTURE.md](ARCHITECTURE.md) · [DATA_MODEL.md](DATA_MODEL.md) · [TESTING.md](TESTING.md) · [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) · [CHANGELOG.md](CHANGELOG.md) · [CLAUDE.md](CLAUDE.md)

## מה יש בגרסה 0.2.1

הטבלה המלאה והישרה - מה פועל, מה נבדק אוטומטית ומה לא - נמצאת ב-[FEATURES.md](FEATURES.md). בקצרה:

* **אימון (חלק 1):** תוכניות, אימון פעיל עם טבלת סטים, טיימר מנוחה שממשיך כשהמסך נעול, שמירה אוטומטית וחידוש, ספריית 104 תרגילים (קישור הדגמה הוא תמיד חיפוש ביוטיוב אלא אם הזנת קישור בעצמך).
  מ-0.2.0: כפתורי `+/-` לפי צעד המשקל של כל תרגיל, התקדמות כוללת באימון, נתוני האימון הקודם ליד הסט, ודירוגי התאוששות אופציונליים.
* **התקדמות:** דשבורד מחושב מהנתונים שלך, אנליטיקה לכל תרגיל (1RM משוער - תמיד מסומן כהערכה), סטים לקבוצת שרירים (עם ההנחות), גרפים אינטראקטיביים עם סינון תקופה,
  שיאים אישיים, יעדים, התאוששות ועומס (רמז ל-Deload בלבד, בלי אבחנות) ותובנות מבוססות כללים (לא AI).
* **Progressive Overload:** המלצה לכל תרגיל לפי Double Progression, עם הסבר, ראיות ורמת ביטחון. אפשר להתעלם או לשנות ידנית; המערכת **לא משנה משקלים בעצמה**, ובנתונים דלים היא אומרת שאין מספיק נתונים.
* **יומן:** חודש / שבוע / יום / רשימה / היסטוריה, אירועים מכל הסוגים (כולל חזרות), העברה / דילוג / "לא בוצע" לאימון מתוכנית בלי לשנות את התוכנית וההיסטוריה, קישור אירוע לאימון שנרשם.
* **גוף:** משקל, 7 היקפים, אחוז שומן, נסיבות מדידה, שדות מותאמים, גרף לכל שדה עם ממוצע נע ו"מגמה מול רעש", השוואות, אזהרה על ערך חריג, ו**תמונות התקדמות** (פרטיות, השוואת לפני/אחרי).
* **נתח עם AI:** דוח מוכן להעתקה או שיתוף ל-ChatGPT / Claude (אימון בודד, שבוע, חודש, 12 שבועות, טווח מותאם או הכול), עם תצוגה מקדימה, ייצוא TXT / PDF / JSON / CSV.
  האפליקציה **מעתיקה ומשתפת בלבד** - היא לא שולחת דבר לשום שירות.
* **גיבוי:** JSON או ZIP עם תמונות, תצוגה מקדימה עם זיהוי כפילויות, מיזוג או החלפה (עם אישור ועותק בטיחות), ייבוא Floot (ללא אימות מול קובץ אמיתי), ומחיקת כל הנתונים.
* **תזכורות:** אימון מתוכנן, שקילה, מדידת היקפים, סיכום שבועי, גיבוי - כל אחת עם מתג משלה.

> **לא נבדק על מכשיר.** כל הבדיקות רצות ב-CI (JVM ו-Robolectric). שום חלק לא הורץ על Galaxy S26 Ultra או על אמולטור: התראות במסך נעול, מצלמה וגלריה, ציור ה-PDF, חיסכון הסוללה של Samsung והתנהגות הגרפים על המסך האמיתי דורשים בדיקה שלך.

## התקנה על Samsung Galaxy S26 Ultra

הקובץ נבנה אוטומטית ב-GitHub Actions בכל Push (ראה "בנייה" למטה).

1. ב-GitHub פתח **Actions** ← הריצה האחרונה (V ירוק) ← למטה **Artifacts** ← הורד `liftos-debug-apk` (קובץ ZIP) והוצא ממנו את `app-debug.apk`.
   אפשר לעשות זאת ישירות מהטלפון בדפדפן או באפליקציית GitHub.
   **איזה קובץ?** `liftos-debug-apk` הוא קובץ ההתקנה לניסיון. `liftos-release-apk` הוא גרסה מוקטנת (R8) שנחתמת **באותו מפתח debug משותף** - היא אינה גרסת הפצה חתומה (ראה "חתימת Release" למטה).
   **אימות:** בלוג הריצה (שלב "Failure summary", סוף הלוג) ובארטיפקט `apk-info` מופיעים ה-Commit, מזהה הריצה, `SHA-256`, שם החבילה (`app.liftos`) והגרסה. אפשר להשוות לקובץ שהורדת:
   `sha256sum app-debug.apk`.
2. פתח את ה-APK בטלפון. אנדרואיד ישאל על התקנה ממקור לא מוכר: ב-**הגדרות ← אבטחה ופרטיות ← התקנת אפליקציות לא מוכרות** אשר לדפדפן/מנהל הקבצים שפתחת ממנו.
3. אשר את ההתקנה. בכניסה הראשונה האפליקציה תבקש הרשאת התראות (לא חובה, משמשת רק להתראת סיום מנוחה והתזכורות).
   כדי שטיימר המנוחה והתזכורות יעבדו בטוח כשהמסך נעול ב-Samsung: **הגדרות ← אפליקציות ← LiftOS ← סוללה ← ללא הגבלה**. זו המלצה בלבד - לא נבדק על מכשיר.
4. עדכון גרסה: התקן את ה-APK החדש מעל הישן. **כל ה-APK-ים נחתמים באותו מפתח** ולכן העדכון שומר את הנתונים. אל תסיר את האפליקציה לפני שיצרת גיבוי.
5. **עדכון מגרסה 0.1.0 ל-0.2.0:** מסד הנתונים עובר אוטומטית מיגרציה (גרסה 1 ← 2) שרק מוסיפה עמודות וטבלאות ולא מוחקת דבר (נבדקת בבדיקה שבונה מסד 1 אמיתי).
   בכל זאת, **ייצא גיבוי לפני העדכון הראשון** - בדיקה אוטומטית אינה תחליף לבדיקה על הנתונים האמיתיים שלך.

> חשוב: הסרת האפליקציה מוחקת את כל הנתונים. לפני החלפת טלפון או הסרה ייצא גיבוי (הגדרות ← שמור גיבוי מלא) ושמור אותו מחוץ למכשיר, למשל ב-Drive.

## בנייה

דרישות: Android Studio בגרסה שתומכת ב-AGP 9.4 (או JDK 17+ עם Android SDK 37 משורת הפקודה).

```bash
# בדיקות (domain על ה-JVM + app על Robolectric)
./gradlew :domain:test :app:testDebugUnitTest

# Debug APK  ->  app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:assembleDebug

# Release APK ממוזער (R8)  ->  app/build/outputs/apk/release/
./gradlew :app:assembleRelease
```

אם אין לך Android SDK (למשל סביבה מוגבלת), אפשר להריץ רק את מודול הלוגיקה:
`./gradlew -Pliftos.domainOnly=true :domain:test`.

### חתימת Release עם מפתח פרטי

כברירת מחדל ה-Release נחתם במפתח ה-Debug המשותף (כדי שיהיה ניתן להתקנה). אם ברצונך מפתח פרטי:

```bash
keytool -genkeypair -v -keystore liftos-release.jks -alias liftos -keyalg RSA -keysize 2048 -validity 36500
```

צור בשורש הפרויקט קובץ `keystore.properties` (הוא ב-`.gitignore`, לעולם אל תעלה אותו ל-Git):

```properties
storeFile=liftos-release.jks
storePassword=...
keyAlias=liftos
keyPassword=...
```

ואז `./gradlew :app:assembleRelease`. שים לב: מפתח אחר = חתימה אחרת, ולכן מעבר מ-Debug ל-Release (או להפך) מחייב הסרת האפליקציה.
ייצא גיבוי לפני כן ושחזר אחרי ההתקנה.

## פרטיות והרשאות

* **אין הרשאת אינטרנט**, אין פרסומות ואין Analytics. הנתונים נשארים על המכשיר.
* ההרשאות היחידות: התראות, Foreground Service (טיימר מנוחה), רטט, WakeLock (בזמן מנוחה) ו-`RECEIVE_BOOT_COMPLETED` (רק כדי שהתזכורות יחזרו אחרי הפעלה מחדש).
  **אין** מצלמה (התמונה מגיעה מאפליקציית המצלמה של המערכת), גלריה/אחסון (בורר התמונות של המערכת), מיקום או אנשי קשר.
* "נתח עם AI" רק מעתיק או משתף טקסט/קובץ. כפתורי "פתח ChatGPT / Claude" מעתיקים את הדוח ואז מעבירים אותו לאפליקציה המותקנת (שיתוף מקומי במכשיר), או פותחים אותה, או פותחים את האתר כדי שתדביק - האפליקציה לעולם לא שולחת את הדוח בעצמה לשום מקום.
  מדדי גוף והערות נכנסים לדוח רק אם סימנת אותם (מדדי גוף כבויים כברירת מחדל), ורואים את הדוח המלא לפני ההעתקה.
* תמונות ההתקדמות נשמרות בתיקייה הפרטית של האפליקציה (לא בגלריה), עם הסרת מטא-דאטה של מיקום ומצלמה.
* אפשר למחוק את כל הנתונים: הגדרות ← מחיקת נתונים (דורש הקלדת "מחק").
