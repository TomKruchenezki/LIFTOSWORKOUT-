# LiftOS

אפליקציית Android אישית לתיעוד אימוני כוח, ניהול תוכניות, מדדי גוף והתקדמות. עובדת לגמרי ללא אינטרנט, בעברית ו-RTL,
עם עיצוב כהה בגוון פחם והדגשות ירוק-ליים. כל הנתונים נשמרים על המכשיר בלבד.

* Kotlin, Jetpack Compose, Material 3, Room (SQLite), Coroutines/StateFlow, Navigation Compose, DataStore
* שני מודולים: `:domain` (לוגיקה טהורה, נבדקת על ה-JVM) ו-`:app` (Android)
* פרטים: [ARCHITECTURE.md](ARCHITECTURE.md) · [DATA_MODEL.md](DATA_MODEL.md) · [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) · [CHANGELOG.md](CHANGELOG.md) · [CLAUDE.md](CLAUDE.md)

## מה עובד בגרסה 0.1.0

* **בית:** האימון הבא (לפי ימי השבוע בתוכנית), "התחל אימון"/"המשך אימון", אימונים השבוע והחודש, משקל אחרון ושינוי ל-7 ו-30 יום, אימון אחרון, מטרה נוכחית, גישה מהירה לתוכניות.
* **תוכניות:** כמה תוכניות שרוצים; שם, תיאור, מטרה; ימי אימון ויום קבוע לכל אימון; תרגילים עם סטים, טווח חזרות, משקל יעד, RIR/RPE, זמן מנוחה, סטי חימום והערות;
  הוספה, החלפה, שכפול, מחיקה וגרירה לשינוי סדר; שכפול תוכנית, שמירה כתבנית ויצירה מתבנית. תוכנית ההתחלה (Upper A / Lower A / Upper B / Lower B) כלולה וניתנת לשינוי מלא.
* **אימון פעיל:** טבלת סטים (משקל, חזרות, RIR/RPE, בוצע) עם מקלדת מספרית וסרגל `+/-` מעל המקלדת; ערכי האימון הקודם נטענים כנקודת פתיחה בלי לסמן סטים כבוצעו;
  סטי חימום ועבודה, דרופ סט, כשל שרירי, תרגילים חד-צדדיים (ימין/שמאל), הוספה/החלפה/הסרה/דילוג/סידור תרגילים באמצע אימון, הערות, דירוג אנרגיה והרגשה;
  טיימר מנוחה (השהיה, +15, +30, איפוס, דילוג) שממשיך לפעול כשהמסך נעול, עם התראה ורטט;
  שמירה אוטומטית מיידית וחידוש אימון אחרי סגירה לא צפויה.
* **סיכום אימון:** משך, נפח, סטים, חזרות, פירוט, שיאים אישיים, השוואה לאימון הקודם מאותו סוג, העתקה כטקסט, שיתוף, ייצוא JSON/CSV, **"העתק דוח לניתוח ב-ChatGPT"**.
* **יומן והיסטוריה:** רשימה לפי חודשים, עריכה מלאה של אימון שהסתיים (משקל, חזרות, תאריך, שעות), הוספת אימון מהעבר, הוספת פעילות/הערה.
* **ספריית תרגילים:** 104 תרגילים בעברית ואנגלית עם הוראות, טעויות נפוצות, בטיחות וחלופות; חיפוש וסינון; תרגילים אישיים.
  קישור הדגמה הוא תמיד **חיפוש ביוטיוב** (מסומן ככזה) אלא אם הזנת בעצמך קישור לסרטון.
* **מדדי גוף:** משקל, 6 היקפים, אחוז שומן והערות (כל שדה אופציונלי), עריכה ומחיקה עם אישור, גרף משקל עם ממוצע נע וטווחי זמן.
* **גיבוי:** ייצוא JSON עם גרסת Schema, שחזור עם תצוגה מקדימה ואימות, מיזוג או החלפה (עם אישור ועותק בטיחות אוטומטי), בחירת קובץ מ-Google Drive דרך בורר הקבצים, ייבוא מהאפליקציה הקודמת (Floot, ללא אימות מול קובץ אמיתי).

## התקנה על Samsung Galaxy S26 Ultra

הקובץ נבנה אוטומטית ב-GitHub Actions בכל Push (ראה "בנייה" למטה).

1. ב-GitHub פתח **Actions** ← הריצה האחרונה (V ירוק) ← למטה **Artifacts** ← הורד `liftos-debug-apk` (קובץ ZIP) והוצא ממנו את `app-debug.apk`.
   אפשר לעשות זאת ישירות מהטלפון בדפדפן או באפליקציית GitHub.
2. פתח את ה-APK בטלפון. אנדרואיד ישאל על התקנה ממקור לא מוכר: ב-**הגדרות ← אבטחה ופרטיות ← התקנת אפליקציות לא מוכרות** אשר לדפדפן/מנהל הקבצים שפתחת ממנו.
3. אשר את ההתקנה. בכניסה הראשונה האפליקציה תבקש הרשאת התראות (לא חובה, משמשת רק להתראת סיום מנוחה).
4. עדכון גרסה: התקן את ה-APK החדש מעל הישן. **כל ה-APK-ים נחתמים באותו מפתח** ולכן העדכון שומר את הנתונים. אל תסיר את האפליקציה לפני שיצרת גיבוי.

> חשוב: הסרת האפליקציה מוחקת את כל הנתונים. לפני החלפת טלפון או הסרה ייצא גיבוי (הגדרות ← שמור גיבוי מלא) ושמור אותו מחוץ למכשיר, למשל ב-Drive.

## בנייה

דרישות: Android Studio בגרסה שתומכת ב-AGP 9.4 (או JDK 17+ עם Android SDK 37 משורת הפקודה).

```bash
# בדיקות (domain על ה-JVM + app על Robolectric)
./gradlew :domain:test :app:testDebugUnitTest

# Debug APK  ->  app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:assembleDebug

# Release APK ממוזער (R8)  ->  app/build/outputs/apk/release/
./gradlew :app:assembleRelease
```

אם אין לך Android SDK (למשל סביבה מוגבלת), אפשר להריץ רק את מודול הלוגיקה:
`./gradlew -Pliftos.domainOnly=true :domain:test`.

### חתימת Release עם מפתח פרטי

כברירת מחדל ה-Release נחתם במפתח ה-Debug המשותף (כדי שיהיה ניתן להתקנה). אם ברצונך מפתח פרטי:

```bash
keytool -genkeypair -v -keystore liftos-release.jks -alias liftos -keyalg RSA -keysize 2048 -validity 36500
```

צור בשורש הפרויקט קובץ `keystore.properties` (הוא ב-`.gitignore`, לעולם אל תעלה אותו ל-Git):

```properties
storeFile=liftos-release.jks
storePassword=...
keyAlias=liftos
keyPassword=...
```

ואז `./gradlew :app:assembleRelease`. שים לב: מפתח אחר = חתימה אחרת, ולכן מעבר מ-Debug ל-Release (או להפך) מחייב הסרת האפליקציה.
ייצא גיבוי לפני כן ושחזר אחרי ההתקנה.

## פרטיות

אין הרשאת אינטרנט, אין פרסומות, אין Analytics. ייצוא ושיתוף קורים רק כשאתה לוחץ. "העתק דוח לניתוח" רק מעתיק טקסט ללוח
(או פותח את בורר השיתוף של אנדרואיד) - האפליקציה לעולם לא שולחת אותו לשום שירות בעצמה.
